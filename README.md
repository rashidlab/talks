## Repository conventions

- Decks are authored in [Quarto RevealJS](https://quarto.org/docs/presentations/revealjs/).
- Source: `<date>-<venue>-<topic>-deck/<topic>.qmd`
- Rendered output (committed): the corresponding `.html` plus its `_files/` directory
- Lab branding (`custom.css`, logos) is duplicated locally per deck rather than symlinked, so each deck remains self-contained when published.
